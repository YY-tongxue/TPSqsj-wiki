📖 使用说明：武器数据怎么改 ​

这份说明写给「不太懂代码」的管理员。平时你只需要改一个文件（weaponDB.js），其他都不用动。

一、整个站是怎么运转的 ​

┌──────────────────────────────────────────────────────────────┐
│  武器总库 weaponDB.js（唯一信息源，每把武器只写一次）              │
│  → 名称 / 图标 / 属性 / 系列 / 评测 + rank 档位字段              │
└───────────────────────┬──────────────────────────────────────┘
                        │ 自动读取
        ┌───────────────┼───────────────────┐
        ▼               ▼                   ▼
  职业排行（PVP/PVE/平民）   职业图鉴页          资料库 /library/
  自动按 rank 分组展示      显示该职业排行       卡片视图 + 表格对比
  （RankChart 组件）        （RankChart）       （WeaponCatalog）

核心思想：

  • 武器信息只写一次（weaponDB.js），排行、图鉴、资料库全部自动读取
  • 档位 = 每把武器的一个字段：rank: { pvp: 'T1', pve: 'T0', f2p: 'T2' }
  • 改档位、加武器、改属性，永远只动 weaponDB.js 这一个文件

二、先认识武器 id 和 rank 字段 ​

每把武器在 weaponDB.js 里是一个对象，左边是它的 id（英文键），里面带 rank 字段：

js
'lib-bladedancer-001': {                     // ← 武器 id（英文键，全站唯一）
  name: '马卡洛夫之刃',                       // 武器名
  classKey: 'bladedancer',                   // 所属职业（英文标识）
  series: '背刺系',                          // 所属系（决定它在资料库哪个表/组）
  family: '马卡洛夫',                        // 官方系列（可选，同系列填一样 → 自动合集）
  icon: '/images/weapons/makarov-blade.png', // 图标路径
  desc: '背刺系·官方属性数据',                 // 一句话说明
  rank: { pvp: 'T3', pve: 'T2' },            // ← 档位在这（不填的分类不出现在该榜）
  stats: {                                   // 属性表（资料库/详情页展示）
    '装备时间': '0.50秒',
    '移动速度': '800点',
    ...
  },
  detail: '详细介绍……',                      // 详情页评测（可空，自动给占位说明）
},

rank 三个分类各自独立：

分类含义不填会怎样
pvp玩家对战强度不出现在 PVP 榜
pve副本/清怪强度不出现在 PVE 榜
f2p免费/平民性价比不出现在平民榜

档位从强到弱：T0 → T0.5 → T1 → T1.5 → T2 → T2.5 → T3

三、怎么给武器排档位（最常用） ​

① 升/降档 ​

打开 weaponDB.js，找到武器，改 rank 里的值：

js
// 改之前：马卡洛夫之刃在 T3
'lib-bladedancer-001': { ..., rank: { pvp: 'T3' } }

// 改之后：升到 T1（其他都不用动）
'lib-bladedancer-001': { ..., rank: { pvp: 'T1' } }

② 给资料库武器排进某个榜 ​

找到资料库武器（lib- 开头），补上 rank 字段：

js
'lib-bladedancer-030': {                     // 例如某把还没上榜的武器
  name: '……',
  classKey: 'bladedancer',
  ...
  rank: { pvp: 'T0' },                       // ← 加上这行，进 PVP 榜 T0
},

③ 同一个档位里谁在前 ​

同一档位内，武器在文件里的先后顺序 = 强弱顺序（上面的先显示）。想调整就把整块代码上下移动。

④ 踢出某分类榜 ​

把对应分类的值删掉即可：

js
rank: { pvp: 'T1' }   // 只留 pvp，pve / f2p 自动从对应榜消失

保存后刷新页面即可看到变化。id 或档位名写错（如 T01、多空格）会导致该武器不显示。

四、怎么加一把新武器 ​

  1. 图标放进 public/images/weapons/（或先不填，用占位图 lib-weapon.svg）
  2. 在 weaponDB.js 末尾抄一把现有武器，改成新武器信息 + rank
  3. 运行 npm run gen-weapons（自动生成详情页）
  4. 刷新页面

新增示例（复制粘贴改内容）：

js
'my-new-weapon': {
  name: '我的新武器',
  classKey: 'bladedancer',        // 职业英文标识，见下方对照表
  series: '背刺系',               // 所属系（资料库分组用）
  category: '近战',
  icon: '/images/weapons/my-new-weapon.png',
  desc: '一句话评价',
  rank: { pvp: 'T1', pve: 'T0.5', f2p: 'T2' },
  stats: { 伤害: '100', 射速: '5发/s' },
},

职业英文标识对照：

职业英文标识职业英文标识
刀锋bladedancer狙击sniper
双枪dualpistol医生medic
机枪heavy榴弹grenade
烈焰flame工程师engineer
导弹missile弓箭archer

五、怎么删一把武器 ​

从 weaponDB.js 里删掉整个武器对象（从 'id': { 到 },），再跑 npm run gen-weapons。

只是不想它上榜？把 rank 删掉就行，武器还在资料库里。

六、资料库：卡片视图和表格对比 ​

资料库（/library/）默认是卡片视图（美观不挤）：

  • 每把武器一张卡片：图标 + 名称 + 系列/系标签 + 4 个核心属性
  • 点击卡片 → 跳武器详情页看全部属性
  • 顶部可以切换「📋 表格对比」视图，同系武器并排比数值

卡片上显示的 4 个核心属性在 .vitepress/theme/data/tiers.ts 的 keyStats 里定义（每职业 3~4 个），一般不用改。

武器属性数据在 weaponDB.js 的 stats 字段里：

  • 加属性：在 stats 里加 '属性名': '值'
  • 改系名/表头：.vitepress/theme/data/catalog.ts（一般不用动）

六·五、官方系列合集怎么填 ​

官方武器有「系列」归属（比如马卡洛夫之刃属于马卡洛夫系列）。要给武器标系列：

  1. 在 weaponDB.js 武器对象里加 family 字段：
js
'lib-bladedancer-001': {
  name: '马卡洛夫之刃',
  family: '马卡洛夫',          // ← 系列名，同系列的填一样
  ...
},
  1. 跑 npm run gen-weapons 重新生成详情页
  2. 效果：
    • 详情页自动出现「🏷️ 马卡洛夫 系列合集」区块，列出同系列其他武器（点击互跳）
    • 资料库卡片和表格里显示 🏷️ 系列标签
    • 不填 family 的武器不参与系列合集

七、怎么换图标 ​

  1. 把图片放进 public/images/weapons/（文件名英文，如 my-weapon.png）
  2. weaponDB.js 里 icon 改成：/images/weapons/my-weapon.png

图标是单图（不做悬停变换）。资料库武器暂用统一占位图 lib-weapon.svg， 你在游戏里截图后替换同名文件即可。游戏内武器卡片是横图，直接裁剪武器本体放进去效果最好。

八、常见问题 ​

Q：加了武器，详情页没生成？ ​

运行 npm run gen-weapons（项目根目录终端）。

Q：改了数据没反应？ ​

  • 确认保存了 weaponDB.js
  • 确认 npm run dev 还在运行（终端没关）
  • 刷新浏览器（Ctrl+F5 强制刷新）

Q：武器在资料库有，但排行榜不显示？ ​

排行榜只看 rank 字段。给该武器补上对应分类的档位（如 rank: { pvp: 'T1' }）。

Q：图标不显示 / 裂图？ ​

  • 检查 icon 是否以 /images/weapons/ 开头
  • 检查文件名大小写是否和磁盘一致

Q：三个分类（PVP/PVE/平民）怎么各自排名？ ​

每个分类是独立的 rank 值（rank.pvp / rank.pve / rank.f2p），互不影响，分别填即可。

Q：资料库表格视图列太多、数字挤？ ​

资料库默认卡片视图不挤；需要表格对比时切「📋 表格对比」，列内自动换行、无横向滚动。也可以把不常用的属性列从 catalog.ts 的 columns 里删掉（只影响资料库显示，不影响数据）。
