参与共建 ​

欢迎一起完善这个武器资料库！

你可以做什么 ​

1. 提交数据勘误 ​

  • 武器面板数据有误
  • 排行榜档位不合理
  • 特殊效果描述不准确

2. 补充武器词条 ​

  • 为空白职业添加武器页面
  • 补充武器截图、实战评测
  • 添加版本改动历史

3. 提交实战心得 ​

  • 某把武器的使用技巧
  • 克制关系说明
  • 地图适配建议

协作方式 ​

本站基于 VitePress 构建，使用 Git 管理内容：

  1. Fork 仓库到自己账号
  2. 本地修改 Markdown 文件
  3. 提交 Pull Request
  4. 管理员审核后合并上线

主要数据文件 ​

武器数据采用「总库」结构，武器信息只写一次：

文件作用
.vitepress/theme/data/weaponDB.js武器总库：每把武器的名称/图标/属性/评测 + rank 档位，只写一次
.vitepress/theme/data/tiers.ts排行系统定义：分类/职业/重要属性（一般不用改）
.vitepress/theme/data/catalog.ts资料库·系定义（表头/说明，一般不用改）

添加一把新武器 ​

  1. 准备图标放入 public/images/weapons/
  2. 在 weaponDB.js 里加武器数据（含 id 和 rank 档位）
  3. 运行 npm run gen-weapons 自动生成详情页
  4. 运行 npm run build 打包上传

💡 详细教程看 📖 排行榜使用说明。
