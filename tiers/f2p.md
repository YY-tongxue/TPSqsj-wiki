# 平民性价比排行榜

> 全职业武器强度排行（免费 / 低获取成本环境），不看抽奖、限定、氪金武器，适合零氪和微氪玩家参考。
> 🖱️ **鼠标悬停**武器可预览重要属性，**点击**查看全部属性与完整词条。

## 怎么排

- 每把武器的档位写在 `weaponDB.js` 的 `rank: { f2p: 'T1' }` 字段，**改档位 = 改这个值**
- 档位从强到弱：T0 → T0.5 → T1 → T1.5 → T2 → T2.5 → T3
- 不填 `f2p` 的武器不会出现在本榜

## 省钱建议

1. **先把金币武器拉满**：前期优先用金币购买的武器，钻石/点券留给限定武器。
2. **关注活动送武器**：版本活动、登录奖励经常送紫品质武器，性价比极高。
3. **不要盲目强化白板**：白绿品质武器强化材料投入回报率低。
