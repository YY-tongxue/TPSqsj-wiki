# PVE 排行榜

> 全职业武器强度排行（PVE 环境），以清怪效率、BOSS 输出、生存能力、技能联动为主要评价维度。
> 🖱️ **鼠标悬停**武器可预览重要属性，**点击**查看全部属性与完整词条。

<RankChart mode="pve" />

## 怎么排

- 每把武器的档位写在 `weaponDB.js` 的 `rank: { pve: 'T1' }` 字段，**改档位 = 改这个值**
- 档位从强到弱：T0 → T0.5 → T1 → T1.5 → T2 → T2.5 → T3
- 不填 `pve` 的武器不会出现在本榜

> 📖 完整操作说明看 [使用说明](/guide/tier-guide)。
